# JOINT app prototype — profile, stars and owner admin update

This build adds: editable profile, profile picture preview/storage, writing and attaching images/videos to posts, edit/delete post controls, star-based follow buttons, and a separate Owner Admin prototype for host review, payment/subscription records, payout requests and promotions.

## Important limits
This is a static browser-local demo. localStorage is device/browser-specific and does not publish to other users, securely verify uploaded certificates, prove a payment, or initiate real payouts. Admin access is NOT protected. For production, connect authenticated users, Supabase database and private storage, server-side review permissions, payment webhooks and payout APIs. Do not use real identity documents or real financial transactions in this demo.

## Run
Keep the files together in one folder and open `index.html` with your development server/browser.
